# Setup Evidence Checklist

Tick each item only after you have genuinely completed it.

- [ ] Docker installed and the Juice Shop image downloaded.
- [ ] `docker compose up -d` completed.
- [ ] `docker compose ps` screenshot saved.
- [ ] Browser screenshot saved showing `http://127.0.0.1:3000`.
- [ ] Network inspection screenshot saved showing `"Internal": true`.
- [ ] Lab topology diagram included (`lab-topology.svg`).
- [ ] Rules of Engagement completed, personally signed, and dated.
- [ ] Test log updated with at least one safe local observation.
- [ ] Screenshots reviewed for passwords, tokens, and personal data.
- [ ] All supporting files placed in one public or view-only repository/folder.

Suggested evidence filenames:
- `evidence/docker-status.png`
- `evidence/local-target.png`
- `evidence/network-isolation.png`

Do not create substitute or fabricated screenshots. Capture these from your own lab.
